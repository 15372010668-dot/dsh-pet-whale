# 图片素材说明

README 已引用本文件夹内的以下素材，**已全部就位**。若要更换，保持同名覆盖即可。

| 文件 | 用在哪 | 规格 |
| --- | --- | --- |
| `hero.mp4` | README 首屏（自动循环播放） | 鲸鱼跳跃实拍，无需转格式 |

## 更换素材的方法

1. 录屏：`Shift + Cmd + 5` → 录制屏幕（mp4 直接可用，**无需转 GIF**）；
2. 静态截图：`Shift + Cmd + 4`；
3. 按上表文件名覆盖本文件夹内的文件，提交推送即可。
